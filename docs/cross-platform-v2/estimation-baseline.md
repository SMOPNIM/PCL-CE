# V2 估算基线

> 本文件固定 V2 修订计划的估算口径、WBS 和日历情景。后续基线调整必须在此更新并记录原因。

## 1. 三层估算口径

| 口径 | 含义 |
|---|---|
| 直接工作量 | WBS 中实际设计、编码、测试、文档的人月 |
| 缓冲 | 15–20%，覆盖返工、未知依赖、平台差异 |
| 日历 | 直接工作量 ÷（FTE × 0.8 利用率）+ 阶段重叠 |

管理、QA、评审、集成和等待时间都计入 WBS，不再隐藏。

## 2. 修订 WBS

| 工作包 | 原估算（人月） | V2 估算（人月） | 说明 |
|---|---:|---:|---|
| A. 项目管理/架构 | 0.75–1.0 | 3.0–5.0 | 10–15%，含评审、协调、风险、变更控制 |
| B. Core 去 WPF + 平台抽象 | 2.0–3.5 | 2.5–3.5 | 含 DI/组合根改造；Phase 0 审计后暂定上调至 3.5–5.0，待批准 |
| C. Windows 平台 | 0.75–1.0 | 0.75–1.0 | Windows 作为参考实现 |
| D. Linux 平台 | 1.25–2.0 | 1.5–2.5 | XDG、libsecret、Shell、主题、进程 |
| E. Avalonia UI 基础层 | 2.5–4.0 | 2.5–4.0 | 样式、主题、控件、动画、模糊降级 |
| F. P0 页面迁移 | 2.5–4.0 | 3.0–4.5 | 按页面复杂度分级 |
| G. 本地 Mod 管理 B | 5.0–7.0 | 5.0–7.0 | 分两批交付 |
| H. Minecraft 启动链 | 2.5–4.0 | 3.5–5.5 | Linux 加载器/旧版本/Java 矩阵 |
| I. AppImage/CI/打包 | 1.0–1.5 | 1.5–2.0 | AppImage、Windows 包、CI、发布 |
| J. QA/回归/文档 | 1.5–2.5 | 4.0–6.0 | 0.5 FTE 从 Phase 1 起贯穿 |
| **合计** | **20–30** | **27–41** | P50 约 32–36；B 调整后暂定 28–42.5 |

建议预算：**38–42 人月**（含 15–20% 缓冲）。
若只有 3 人且 Avalonia/Linux 经验不足，按 **42–48 人月** 做预算。

## 3. 日历情景

| 情景 | 团队 | 直接工作量 | 含缓冲 | 日历 |
|---|---|---:|---:|---:|
| 最佳 | 4 人，熟悉 Avalonia + Linux，范围冻结 | 30–34 | 36–40 | 11–13 个月 |
| 基准 | 3.5 人，一般经验 | 32–38 | 38–44 | 13–15 个月 |
| 保守 | 3 人，经验不足 | 36–42 | 42–50 | 15–18 个月 |

## 4. Mod 管理分批

- **Batch 1（Phase 2 前半）**：扫描、列表、图标、启用/禁用、删除、导入、搜索、排序。
- **Batch 2（Phase 2 后半）**：依赖/重复/不兼容分析、Jar-in-Jar、导出、批量操作。

Phase 2 Gate 要求两批都完成；Batch 1 先让 UI 和测试跑起来。

## 5. Phase 0 审计后的暂定调整（未基线）

2026-10-31 代码审计发现：

- `PCL.Core` 有 67 个文件直接引用 WPF，其中 26 个在 `UI/` 目录之外。
- 现有 WPF 启动器约 172,312 行（`.cs` + `.xaml`）。
- `PCL.Core/UI` 约 11,039 行，不能靠改目标框架直接移除。
- 平台相关实现分散在注册表、DPAPI、P/Invoke、Shell、Java 扫描、HTTP 代理等位置。

因此 B 包“Core 去 WPF + 平台抽象”存在上调风险：

| 项目 | 已批准基线 | 暂定调整 | 差额 |
|---|---:|---:|---:|
| B. Core 去 WPF + 平台抽象 | 2.5–3.5 人月 | 3.5–5.0 人月 | +1.0–1.5 |
| 直接工作量合计 | 27–41 人月 | 28–42.5 人月 | +1.0–1.5 |
| 建议预算 | 38–42 人月 | 约 39–44 人月 | 待重算 |
| 日历 | 13–15 个月 | 可能 +0.5–1 个月 | 待 Gate 0 后确认 |

**状态：暂定，未写入对外承诺。** 需要 Phase 0 结束前完成项目边界拆分和 B 包复核，再提交变更批准。

## 6. 结论

- 不承诺 9–13 个月。
- 对外基线：13–15 个月，38–42 人月。
- Phase 0 通过后，按修订后的 WBS 重新基线，再对外承诺日期。
